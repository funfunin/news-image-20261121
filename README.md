A front-page newspaper image summing up Saturday 21 November 2026's
world news: the AI stock sell-off, Mexico's capture of "El Chapo Isidro",
the Russian missile strike on Kryvyi Rih, the COP31 talks overrunning in
Antalya, the Shenzhen summit peace declaration, and Nvidia halting H200
exports to China. Six AI-generated scenes, composed with PIL into a
1024x1024 front page with the masthead "THE WORLD IN ONE DAY".

## Run

```sh
node main.ts
```

This copies `entry.png` to the output directory (`MAKEFUN_OUTPUT_DIR`,
or `/output` by default). Node 22, stdlib only, no dependencies.
